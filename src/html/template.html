A Simple LinkedList System

This page is an example use-case for a linked list system. It consists of a linked list of Number objects. Each of these objects are displayed on a card below. The commands below the card display are linked to each of the functions of my LinkedList class. My hope is this interactive demo will give some insight into how linked lists work, and how they might be used in a real website.
